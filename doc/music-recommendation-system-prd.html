01 背景与产品契约

1.1 事实、问题与回应

依据输入架构的静态核对记录，现有推荐入口以热榜和固定规则为主；播放累计不能证明有效收听，曝光表存在不等于真实曝光采集已完成；本地音乐生成路径不证明服务可用、模型权重可用或可商用。本文未独立进行运行验证，不能把这些设计依赖视为现成能力。

听众需要找到愿意听且可播放的音乐；创作者需要合规参考并明确控制生成；企业成员首先需要知道素材能否用于当前项目；运营需要知道策略为什么生效，以及如何安全撤回。因此产品先提供可解释标签基线、真实行为口径和资格边界，再以证据决定是否启用语义或学习模型。

契约定义完成证据
主要用户听众、个人创作者、企业成员；运营、算法、内容、合规及发布人员为治理用户每项操作有认证主体、用途与当前范围
触发进入首页、下一首、搜索/相似、浏览模板、查找商用素材或提交治理变更场景及意图明确，不把免费听歌绑定余额
核心工作发现合格音乐 → 实际收听/明确反馈 → 可选收藏、创作或项目采用推荐结果可解释；播放、生成、采用分别有权威结果
共享对象范围、作品版本、推荐请求、许可决定、模板版本、策略组合、事件、治理任务同一对象跨页面可追踪但不跨权限泄露
信任边界推荐不赋予版权，不改账户资金，不代替审核、身份、同意和风控服务最终动作重新核验；失败可恢复但不能绕过限制

1.2 目标与判断方法

目标是无画像也能返回合格内容、显式条件可控、负反馈及时生效、创作确认后才进入交易、企业素材可用性可证明、发布可整组回退。是否提升留存、听歌满意度或首作转化，必须在真实事件基线和预注册实验后评估；本文不承诺提升百分比。

标记约定：“必须/不得”是本稿拟交付的不变量，仍待整体评审；“[建议，待确认]”为产品判断或架构数值起点；“[TBD]”为尚无决策的缺口；“示例”为演示数据，不具有正式规则效力。

03 八场景完整旅程

人物与素材均为示例。共同入口先识别范围、用途与当前同意状态；共同结束以真实业务结果为准，而非按钮点击。

R1 新用户首次发现

入口/前置：新注册听众或合法游客进入首页，无可靠画像。主路径：展示可选风格/场景 → 用户保存或跳过 → 按显式偏好或通用内容生成列表 → 展示理由 → 资格复核起播 → 记录真实曝光和有效收听 → 可收藏或调整偏好。完成：可播放且理由可理解，不要求先完成创作。

分支/恢复：偏好为空仍可继续；资格服务不可确认时提示暂不可用；画像失败返回合规通用池。游客会话不得跨设备拼接，登录合并政策见D-05。余额不足不拦免费听歌。关联 FR-SC-01、FR-PF-01、FR-DG-02；AC-05、09、18。

R2 老用户首页与连续播放

入口/前置：听众打开首页或播放结束请求下一首。主路径：读取获准长期听歌偏好及当前会话 → 场景独立排序 → 去重/作者限频 → 返回并复核播放 → 有效播放更新本场景会话；收藏由业务确认。完成：连续队列可用，首页与下一首可因意图不同而不同。

分支/恢复：主动切歌与播放错误分开；屏蔽作者即时过滤剩余队列，撤销仅解除过滤；旧分页继续原组合但重新核验权限；无下一首明确结束，不重复刷曲补数。关联 FR-SC-02、FR-PF-04、FR-GV-03；AC-06、12、39。

R3 听后创作同类作品

入口/前置：用户在可访问歌曲点击类似风格创作。主路径：核验独立参考/改编许可 → 提供允许的风格/速度/乐器摘要与模板 → 编辑参数 → 原交易模块出报价 → 确认范围、参数、许可和报价 → 创建生成任务 → 展示终态及交易处理。完成：生成服务确认成功，产物按自身权利展示；不是点击即成功。

分支/恢复：无改编权则不携带受限参考，可选择无参考模板；模型/声库商用许可未定不得承诺产物可商用；取消确认不冻结；重试查询原任务；价格变化重新确认。关联 FR-CR-01～04、FR-LC-01；AC-29～32。

R4 新音乐冷启动分发

入口/前置：创作者新版本发布且审核通过。主路径：登记异步分析 → 校验内容特征/质量与资格 → 进入合格探索池 → 分层给试探机会 → 真实曝光去重计预算 → 达到观察条件后比较同类并结合不确定性 → 建议扩量或收缩。完成：分发决定可追踪，用户满意度与覆盖率共同观察。

分支/恢复：分析失败可使用核准元数据走标签基线，不伪称语义就绪；样本不足不判差；可疑流量隔离后重算；换音轨创建新分析版本；下架立即停止新授权。关联 FR-MD-02、FR-EX-01～04；AC-22、25～28。

R5 沉默用户回访

入口/前置：增长人员选择已获订阅授权的人群快照，或用户主动打开历史回访链接。主路径：触达模块检查订阅/账号/频控 → 推荐提供当时合格集合 → 发送 → 用户打开时再次鉴权 → 展示近期作品与仍可访问项目 → 记录实际收听/创作。完成：合法回访行为可统计，与不触达组比较而非宣称最后点击因果。

分支/恢复：快照后退订应阻断发送；过期私有项目不显示标题；空集合不发送；触达失败不伪造已送达；频控及沉默定义未确认则不启用主动触达。关联 FR-SC-04、FR-DG-04；AC-08、20。

R6 企业短视频配乐

入口/前置：企业成员选择当前租户及项目用途。主路径：验证成员资格 → 输入时长范围、无人声、用途等条件 → 公共合法作品与本租户授权素材检索 → 展示分项许可 → 试听 → 下载前实时复核下载及用途 → 项目确认采用。完成：采用记录绑定租户、成员、项目、作品版本与用途，不能写回个人听歌兴趣。

分支/恢复：相同用户切到另一租户后旧列表和下载动作失效；许可到期拒绝新的签发/采用；可播放不代表可下载/商用/改编；跨租户对象统一不可访问。关联 FR-LC-01～04、FR-PF-01；AC-09、33～36。

R7 自然语言找音乐与相似

入口/前置：用户输入“雨夜、无人声、爵士、不要太伤感”或选择合法种子曲。主路径：受限字典解析 → 展示可改结构化条件 → 明确硬/软约束 → 标签匹配 → 返回匹配理由；语义模型只有经验证并同空间才可启用。完成：用户看见真实能力说明，可按匹配依据调整。

分支/恢复：未知词不臆测，要求用户确认；无人声硬条件排除未知人声；空结果仅建议放宽软条件；种子失权不可继续相似请求；模型异常降级并明示。关联 FR-SC-03、FR-MD-01、FR-MD-04；AC-07、21、24。

R8 个性化关闭、保护与删除

入口/前置：当前主体打开隐私设置。主路径：关闭个性化 → 更新同意状态并使旧个性化列表不可续用 → 后续请求不读个人兴趣/历史序列 → 非个性化继续服务；另可启用保护、清空兴趣或删除历史。完成：实际读集证明退出有效，删除任务显示真实覆盖与未完成项。

分支/恢复：保存失败不显示“已关闭”，可暂不继续个性化请求并重试；删除前明确范围，提交后不提供恢复个人数据的撤销；备份恢复/补偿重放先执行删除水位；保护不可被运营白名单放宽。关联 FR-PF-02、03、FR-GV-04；AC-10、11、40。

FR-DG-04 · 权威终态归因与最小记录保全 P0

显示归因成功/无归因/超窗/待核验，保留不确定性；业务事实不能因统计重复而重复收费。数据岗位可更正归因但不得篡改资金终态。
字段：业务任务/采用ID：必填只读；业务终态及确认时间：必填权威来源；请求/模板版本：推荐来源必填/只读；归因窗口版本：必填；实验组与bundle：只读；无归因原因：无归因时必填；资金状态仅镜像展示且标明来源。
